Here's my Jammin' project,

This program plays Happy Birthday on the LilyPad buzzer when the slide switch is in the ON position. I used a conditional to check the position of the slide switch.  

I got my song from Robson Couto at https://github.com/robsoncouto/arduino-songs/tree/master/happybirthday. The code provides the notes, melody, timing, and the loop to run the melody and I adapted it to play using the switch. 

A tip for my past self would be to not get bogged down in the details of the musical code, and to not overcomplicate the problem. I knew I only needed one conditional for the switch to work, yet I still confused myself by messing around with the loop from the code I adapted.

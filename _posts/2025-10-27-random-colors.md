Here's my random color project,

In this project, I created a program that displays a random color on an RGB LED when a button is pressed. 

Press button --> One random color appears  
Hold button --> Color stays constant  
Release button --> LED turns off

A tip for my past self would be to not try to change the color every time the button is held, and to use a state variable so the LED only updates when something changes.

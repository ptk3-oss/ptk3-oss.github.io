Plushy Redux Post, 

In this project I defined two integer variables that represent a button (btn) and a switch (swt), each of which can be set to 0 (off) or 1 (on). Using nested if statements, I wrote logic to update three integer LED variables. The program prints a text description of whether each LED is "ON" or "OFF", based on the input conditions. 

A tip for my past self would be to write out a table for the conditions before coding. My initial design was redundant, but I decided to set the LED variables to default to off, so I would only need one nested conditional block.

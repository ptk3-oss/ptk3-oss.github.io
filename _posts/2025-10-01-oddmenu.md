Odd Menu Post, 

This program takes two user defined inputs, numberChoice and menuOption, and uses conditional logic to give them either a regular or secret menu item. Using modular arithmetic, the program checks whether numberChoice is odd or even, which determines whether a user can access the secret menu. The menuOption input decides which dish they get. 

A tip for my former self would be to copy paste my first conditional block to use for the second. I ended up writing out all of the code by hand when the two blocks were basically the same, aside from dish options.
